    How to use

    1. Pick what the code should contain — a link, Wi-Fi login, contact card, WhatsApp chat, email, phone or SMS — and fill in the fields.
    2. Style it: dot shape, colors and an optional logo. The preview checks that it still scans (enough contrast, logo not too big).
    3. Download as PNG for sharing or SVG for print, or copy the image straight into a document.
    Do these QR codes expire?

    No. The content is stored directly inside the code — there's no redirect service in between, so it works forever and nobody tracks the scans.

    What does error correction do?

    Higher levels (Q, H) add redundancy so the code still scans when part of it is covered or damaged — needed when you add a logo. The trade-off is a denser code. Adding a logo switches to H automatically.
