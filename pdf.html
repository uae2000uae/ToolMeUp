    How to use

    1. Merge: drop several PDFs, drag them into order, optionally enter page ranges per file (e.g. 1-3, 7), then merge.
    2. Split & extract: drop one PDF, select pages by clicking or typing ranges, then extract them, remove them, or split the file every N pages into a ZIP.
    3. Files are processed in this browser tab. Large PDFs may take a few seconds.
    Are my PDFs uploaded?

    No. The PDF library runs inside your browser, so your documents never leave your device — useful for contracts, IDs and invoices.

    Why won't my PDF open?

    Password-protected (encrypted) PDFs can't be edited here. Open the file in a PDF reader, remove the password (or "print to PDF"), then try again.
