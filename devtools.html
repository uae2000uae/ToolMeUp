How to use

      
    
        
  1. JSON: paste JSON and it's validated as you type. Errors show the exact line and column. Format, minify or sort keys, then copy or download.
    2. 
        
  2. Regex: type a pattern and toggle flags. Matches are highlighted live, capture groups are listed, and the replace box previews the result. Tap a cheat-sheet chip to insert it.
    3. 
        
  3. Base64, UUID, Lorem ipsum: results update instantly. Drop a file into Base64 to get a data URL.
    4. 
      

      
Is it safe to paste tokens or private data?
Yes. Everything runs in your browser tab; nothing is sent anywhere. Closing the tab discards the data (except the regex pattern and test text, which are kept on this device for convenience).

      
UUID v4 or v7?
v4 is fully random. v7 starts with a timestamp, so new IDs sort in creation order — better for database primary keys.
